# Задание 1

## Категории данных

### client-mart-estate-db

Описание: данные по недвижимости.

Тип данных: публичные данные.

Риски: искажение данных.

Обоснование: для публичных данных нужно обеспечить корректность, чтобы клиенты могли правильно оценить покупаемый товар/услуг.

Степень риска: незначительный.

### DWH Хранилище

Описание: хранилище для аналитических отчетов отчетов.

Тип данных: внутренние данные.

Риски: утечка данных.

Актуальность риска: эти данные включают информацию, которая может оказаться ценной для конкурентов.

Степень риска: значительный.

### auth-db-1

Описание: данные для аутентификации пользователей.

Тип данных: конфиденциальные данные.

Риски: утечка данных, потеря данных.

Актуальность риска: утечка может привести к взлому всей системы и краже других данных, потеря может привести к сбою сервиса.

Степень риска: критичный.

### crm-db

Описание: общие данные клиентов.

Тип данных: конфиденциальные данные.

Риски: утечка данных, потеря данных.

Актуальность риска: при утечке данные клиентов могут быть использованы злоумышленниками, потеря может привести к потери функциональности программы.

Степень риска: критичный.

### client-mart-db

Описание: данные по недвижимости и сделкам.

Тип данных: конфиденциальные данные.

Риски: утечка данных, потеря данных, искажение данных.

Актуальность риска: при утечке данные клиентов могут быть использованы злоумышленниками, при искажении данных компания может не дополучить прибыль.

Степень риска: критичный.

### client-tour-db

Описание: данные по турам для клиентов.

Тип данных: конфиденциальные данные.

Риски: утечка данных.

Актуальность риска: при утечке данные клиентов могут быть использованы злоумышленниками.

Степень риска: значительный.

### tenant-core-db

Описание: данные по ЖКХ.

Тип данных: конфиденциальные данные.

Риски: утечка данных, потеря данных, искажение данных.

Актуальность риска: утечка или потеря приведет к невозможности оплаты услуг ЖКХ, искажение приведет к репутационным издержкам.

Степень риска: критичный.

### crm-tenant-db

Описание: данные по собственникам.

Тип данных: конфиденциальные данные.

Риски: утечка данных, потеря данных.

Актуальность риска: при утечке данные клиентов могут быть использованы злоумышленниками, потеря может привести к потери функциональности программы.

Степень риска: критичный.
